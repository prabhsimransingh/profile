# Job Search (powered by Pinloop)

An AI-screened job search workflow. [Pinloop](https://github.com/pinloop-ai/pinloop-cli) holds millions of live postings
(Greenhouse, Lever, Workday, LinkedIn, etc.). Claude Code runs the CLI, judges each posting against your resume and
preferences, and you apply only to the ones worth your time. Pinloop searches and judges; it does **not** submit applications.

## Setup (5 minutes, on a machine with normal internet access)

```bash
./setup.sh          # installs pinloop, installs the agent skill
claude              # open Claude Code in this folder
```

Then tell Claude: **"Run `pinloop welcome` and follow the instructions."**
Claude will walk you through sign-in (a browser code), storing your resume, and a first search.

Or by hand:

```bash
npm install -g pinloop
pinloop login                              # opens browser, paste the code back with: pinloop login --code <code>
pinloop profile put resume.pdf             # your resume (keep it out of git; see .gitignore)
pinloop profile put profile/preferences.md # what you want / what rules a job out
pinloop count --country US --posted-after 2026-09-01 "software engineer intern"
pinloop pull --from "career sites" --country US --limit 50 "software engineer intern"
pinloop judge <id>                         # full verdict with reasoning
```

## Layout

| Path | Purpose |
|---|---|
| `setup.sh` | Installs the CLI and the Claude skill |
| `CLAUDE.md` | Instructions Claude Code reads automatically in this folder |
| `profile/preferences.md` | Template: roles, locations, deal-breakers. Edit, then `pinloop profile put` it |
| `daily-screen.md` | The nightly routine prompt (count, pull, judge, shortlist) |
| `applications.md` | Your tracker: what you applied to and outcomes |
| `.claude/skills/pinloop/SKILL.md` | Agent instruction file (generated by `pinloop skill`) |

## Cost and limits

Free to start. Paid plans (3-day trial first) raise the posting/judging limits and allow unattended
schedules. Run bare `pinloop` to see usage. `count` is free; `pull` spends postings, so narrow with counts first.

## Moving this to its own repo

```bash
cp -r job-search ~/job-search && cd ~/job-search && git init && git add . && git commit -m "Initial job search setup"
gh repo create job-search --private --source=. --push
```
Keep it **private**: your resume and preferences live here.
